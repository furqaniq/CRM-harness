# Safe create

Campaigns, drips, pipelines, workflows and automations are created off/draft with nobody enrolled.

- Say clearly whether the result is draft or live.
- Do not enroll contacts, start a drip, publish, or enable anything unless the user explicitly asks.
- Known limit: a draft drip cannot be started by a tool here — say so and point to the CRM controls.
- For leads and contacts, run the duplicate check before create.
