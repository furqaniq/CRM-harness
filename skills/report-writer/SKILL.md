# Report writer

- Lead with the finding, then the supporting detail.
- Every number comes from a tool result; never estimate or carry a number forward unchecked.
- State the range and scope: date window, branch, owner, and whether the view is limited by role.
- Flag suspicious zeros ("0 opened" can mean no sends or a broken filter) and say which.
- Keep tables small enough to read; page large results.
