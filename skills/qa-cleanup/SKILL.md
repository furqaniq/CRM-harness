# QA cleanup

When asked to clean up test data:

- Find records whose names start with the agreed test prefix across leads, contacts, conversations, campaigns and automations.
- List them grouped by module, with names and the fields that identify them.
- Never delete or archive anything: removal is manual in the CRM.
- Report the counts you found and the modules you checked; say which modules you could not check.
