# Scope awareness

Before presenting a result:

- Say what the numbers cover: this branch, this owner, or all records the user may see.
- If the tool is role-scoped or ownership-scoped, say the view is limited and by what.
- Never present a scoped count as the company total.
- If you could not check a module, say so instead of leaving a silent gap.
