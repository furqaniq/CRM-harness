# Large results

When a result is stored as an artifact:

- The summary and handle are in context; the full payload is not.
- Read slices with the artifact tool instead of asking for "all of it".
- Prefer compact tools (counts, filtered searches) over dumping a full list.
- State coverage honestly: "I read the first 200 of 950" — never "all" from a sample.
